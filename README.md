## Instaladores

| Sistema | Arquivo | Instalar |
| --- | --- | --- |
| Windows 10/11 | `MatrixBall_x.y.z_x64-setup.exe` | execute o instalador (NSIS) |
| Windows | `MatrixBall_x.y.z_x64_en-US.msi` | MSI (alternativo) |
| Debian/Ubuntu | `matrix-ball_x.y.z_amd64.deb` | `sudo dpkg -i matrix-ball_*.deb` |
| Qualquer Linux | `MatrixBall_x.y.z_amd64.AppImage` | `chmod +x` e execute |

O link acima sempre aponta para a release mais nova (sem pré-releases).
